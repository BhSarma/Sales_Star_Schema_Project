Sales Star Schema Dashboard (Power BI)

Sales analytics dashboard built on a star schema using sales data (2023-2025).

What I did
- Cleaned data in Power Query (removed duplicates, set data types)
- Built a star schema: 1 fact table + Dim_Product, Dim_Region, Dim_Sales_Channel, Dim_Date
- Created DAX measures: Total Sales, Total Profit, Total Cost, Profit Margin %
- Designed an interactive dashboard with slicers (Year, Region)

Key results (2025)
- Total Sales: 86.47M
- Total Profit: 18.45M
- Profit Margin: 21.34%
